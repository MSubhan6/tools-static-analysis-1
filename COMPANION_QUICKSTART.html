Companion Server Quick Setup

Get up and running in 3 simple steps

Companion Server Not Running
The companion server enables IDE integration (Claude Code, VS Code) and fix workflows. If you have the repository: It's already included - just start it. If you're remote: Download it from the MCP server first.
Windows Installation

If you're using the MCP server remotely (like through Claude Desktop on Windows), download the companion server:

  1. Download: http://localhost:8080/companion/download (saves as companion-server.zip)
  2. Extract: Right-click the ZIP file → Extract All → Choose destination (e.g., C:\companion)
  3. Start:
    cd C:\companion\companion node server.js

    Or use: npm start from the companion directory

Expected output: 
Tools Viewer Companion Agent
============================
  Port:       19280
  Listening on http://127.0.0.1:19280
1 Check Prerequisites

You need Node.js v16+ installed. Check if you have it:

node --version
Don't have Node.js? Install it:
  • Ubuntu/Debian: sudo apt install nodejs npm
  • macOS: brew install node
  • Windows: Download from nodejs.org
2 Verify Setup

If you have the repository, the companion server is already at companion/server.js. For Windows users without the repository, download from the link above.

Unix/Linux/Mac users with repository:

cd dependency-mapper-python ./companion-cli.sh install

Windows users with repository:

cd dependency-mapper-python node companion\server.js --help
Expected output: 
[OK] Node.js v20.x.x installed
[OK] Companion files found at companion/server.js
[OK] Installation check complete
3 Start the Companion

Unix/Linux/Mac users:

./companion-cli.sh start

Windows users:

node companion\server.js

Verify it's running:

curl http://localhost:19280/_ping
Expected output: 
{"status":"ok"}

Troubleshooting

Port 19280 already in use?

./companion-cli.sh start 19281

Windows: node companion\server.js --port 19281

Check if running:

./companion-cli.sh status

Windows: curl http://localhost:19280/_ping

Can't find node command?

Install Node.js from nodejs.org
After installation, restart your terminal

Restart (Unix/Mac):

./companion-cli.sh restart

Windows: Stop the process (Ctrl+C) and run node companion\server.js again
